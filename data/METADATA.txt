## How to Update Production Data

1. Move current files to archive: `mv data/*.csv data/archive/[filename]_YYYYMMDD.csv`
2. Copy new run files from results: `cp results/[run_id]/*.csv data/`
3. Update this METADATA.txt file with new run information
4. Update results/llm_runs_metadata.csv to mark new production run
5. Commit with message noting which run is now active
