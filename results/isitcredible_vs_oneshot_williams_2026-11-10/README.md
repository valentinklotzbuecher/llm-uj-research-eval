# isitcredible vs one-shot on Williams et al. (2024), 10 November 2026

AI-run analysis (Claude Code, Opus 5.5, at David Reinstein's request). One paper, exploratory, AI judges only. Not pooled with the one-shot benchmark or the scaled critique-overlap run. Write-up: `docs/isitcredible_vs_oneshot_williams_2026-11-10.md`. All numbers are in `summary.md` (from `summary.json`), generated by `scripts/compare_isitcredible_williams.py summarize`; this file states none.

## Files

| Path | Contents |
|---|---|
| `freeze.json` | Provenance and hashes of every input; isitcredible and Nature-referee issue counts and severities, frozen before judging |
| `normalize_report.json` | Items kept after the neutral rewrite; leak-scan hit counts |
| `judgments/<judge>/<case>.json` | Judge output mapped back to original ids (categories, confidence), blinding seed, prompt and input hashes |
| `isitcredible_evidence_check.json` | Hand-coded evidence status of each isitcredible finding (step 5) |
| `summary.json`, `summary.md` | Computed coverage, overlap, set differences, cost |
| `spend_ledger.csv` | Tokens and estimated cost per paid call |
| `private/` (ignored) | isitcredible issue texts, Nature-referee issues, neutral rewrites, judge reasons, raw responses, Codex event logs, the peer review file |

`private/` stays local because the repository is public and Joe Francis has not released his unaudited findings; he said he would check them before they were publicized.

## Reproduce

```bash
python scripts/compare_isitcredible_williams.py freeze
python scripts/compare_isitcredible_williams.py normalize
python scripts/compare_isitcredible_williams.py judge --judge claude
python scripts/compare_isitcredible_williams.py judge --judge codex
python scripts/compare_isitcredible_williams.py summarize
```

`freeze` needs `results/reviewer12_joe_shared/SYNTHESIS.md` (local, not tracked) and downloads the Nature peer review file. `normalize` reuses the v2 judge's rewrites of the curated human list and the GPT-5.2 Pro list (`results/issue_match_judge_v2_opus55_2026-11-10/normalized/`) after checking their source text is unchanged.
