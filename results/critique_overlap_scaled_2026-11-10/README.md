# Critique-overlap scaled run (10 November 2026)

AI-run analysis (Claude Code, at David Reinstein's request). Exploratory: the five-paper pilot pipeline (`results/critique_overlap_pilot_2026-11-10/`, design in its README) applied to every eligible paper, with bootstrap intervals over papers. AI judges only; no human validation yet. Not pooled with the one-shot benchmark or the manuscript chapters.

**All results are in [`summary.md`](summary.md)**, generated from `summary.json` by `scripts/critique_overlap_scale.py summarize`. This file states no result numbers. The write-up is `docs/critique_overlap_scaled_2026-11-10.md`.

## What is the same as the pilot

`scripts/critique_overlap_scale.py` imports `scripts/critique_overlap_pilot.py` and does not change it. Extraction prompt and model (Claude Haiku 5.5), model-issue generator (Claude Opus 5.5, condition A, PDF only), judge prompt, blinding, the two judges (GPT `gpt-5.6-terra` via `codex exec`; Claude Sonnet 5.5), the three pairing kinds (real, placebo, human_human) and the three matching rules are the pilot's.

## What differs

- **Papers.** All papers in `data/critique_eligibility_manifest.json` that are eligible and have at least two substantive individual evaluations (30), ordered by SHA-256 of the paper label. The pilot rule also required a known PDF date; two papers here have none and are kept, with a sensitivity table without them. Benabou and Peterman (documented mispairings) are excluded.
- **Evaluation documents** are recorded by `doc_ref` (first 12 hex of the SHA-256 of the export file name) and the file's SHA-256, not by slug or file name, because some slugs carry evaluator names. Issue files carry `source_doc_ref`.
- **Reused work.** The five pilot papers' human-issue files are copied (source hash checked), and so are their real and human_human judgments for both judges (item lists checked identical, so the blinding is the same). Placebo pairings are new, because the paper order differs. Model issues come from, in order: this run's `A/` (four focal-set papers not covered elsewhere), the pilot's `A/`, the 4 Nov run, and the 10 Nov expansion run (`results/claude_opus_5_5_high_keyissues_expansion_2026-11-10/A/`).
- **Name check.** After extraction, each issue's text and quote are checked for reviewer-name tokens taken from the evaluation documents' front matter and titles; none were found.
- **Intervals.** 95% percentile bootstrap over papers (2,000 draws, fixed seed); each draw keeps every pairing of a sampled paper. A paired interval is given for model coverage minus human-to-human coverage.
- The human audit page export (`results/match_audit/`) is not regenerated by this run.

## Files

| Path | Contents |
|---|---|
| `selection.json` | Rule, chosen papers, evaluation doc refs and hashes |
| `human_issues/<paper>__E<k>.json`, `human_issues_frozen.json` | Frozen human issues and freeze record |
| `A/<paper>.json` | Model issues generated in this run (four papers) |
| `judge/<judge>/<pairing>.json` | Matches mapped back to original ids, with blinding record |
| `summary.json`, `summary.md` | Computed results, including `bootstrap` |
| `spend_ledger.csv` | Token usage and estimated cost per paid call |

Raw Codex event streams (`judge/codex/calls/`, `judge/codex/isolated_codex_workdir/`) stay local, as for the pilot.

## Reproduce

```bash
python scripts/critique_overlap_scale.py select
python scripts/critique_overlap_scale.py extract
python scripts/critique_overlap_scale.py generate --only-missing-focal
python scripts/critique_overlap_scale.py judge --judge sonnet
python scripts/critique_overlap_scale.py judge --judge codex
python scripts/critique_overlap_scale.py summarize
python -m unittest tests/test_critique_overlap_scale.py
```
