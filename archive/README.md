# Archive Directory

This directory contains old versions and unused files kept for historical reference.

## Files

### system_prompts.py
Historical system prompts that were used or considered for LLM evaluations. The current system prompt is defined inline in `methods.qmd` as `SYSTEM_PROMPT_COMBINED`. This file is kept for reference but is not used in the current codebase.

Contains:
- `SYSTEM_PROMPT_MANUALFIX_NOUJ` - Full Unjournal guidelines text
- `SYSTEM_PROMPT_GUIDELINES` - Shorter version referencing URL
- `TIERS_SYSTEM_PROMPT_MANUALFIX` - Journal tier prediction focused
- `FULL_GUIDELINES_PROMPT` - Complete evaluator guidelines

### Older .qmd files
- `compare_ratings.qmd` - Early comparison analysis
- `numerical_ratings.qmd` - Early ratings analysis
- `discussion-CONFLICT-1.qmd` - Git merge conflict backup (can be deleted)
- `methods-CONFLICT-1.qmd` - Git merge conflict backup (can be deleted)
