Overview

The Unjournal commissions open, structured evaluations of working papers in economics and social science. A natural question is whether this process actually changes research: do authors engage with the feedback and revise their work?

This page tabulates evidence from approximately 57 tracked evaluations based on manual assessment. For each paper where sufficient time has passed, Unjournal staff assessed whether the authors (a) formally or informally responded to the evaluation, and (b) produced an updated version of the paper that reflects the feedback.

For a subset of papers, automated PDF change detection (line-level diffing of before/after versions) supplements the manual coding. The broader background and framing is discussed in The Unjournal’s knowledge base.

Automated Change Detection (Supplement)

The paper change analysis tool provides automated, reproducible detection of line-level changes between pre- and post-evaluation PDF versions. It:

  1. Extracts text from “before” (evaluated) and “after” (latest available) PDF versions
  2. Computes line-level additions, deletions, and net text change
  3. Optionally uses an LLM to attribute specific changes to evaluator suggestions

This supplements the manual coding above by providing objective, quantitative change metrics — particularly useful for papers where subjective judgment of “updating” is difficult.

NoteRunning the automated pipeline

Results from the automated pipeline will appear here once re-run on current paper pairs. To reproduce:

# Install dependencies
pip install pandas pdfplumber rapidfuzz

# Run from the paper_change_analysis directory of unjournal_tools_interfaces
python scripts/analyze_paper_changes.py

# Optional: LLM attribution (requires OpenAI key)
python scripts/llm_change_attribution.py

See full documentation at https://daaronr.github.io/unjournal_tools_interfaces/paper_change_analysis/.

From an earlier run on 34 paper pairs (a subset of the above), the automated analysis found:

  • 20 papers had matched Unjournal evaluations (title-based matching from evaluation markdown files)
  • 6 papers showed both a matched evaluation and substantial line-level revisions (>50 line changes)
  • 1 paper had over 3,000 net line changes post-evaluation

These automated results are consistent with the manual coding above. The discrepancy in totals (34 vs 57) reflects that the manual tracking has since been extended to more papers.
