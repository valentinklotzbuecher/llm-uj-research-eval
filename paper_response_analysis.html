Overview

The Unjournal commissions open, structured evaluations of working papers in economics and social science. A natural question is whether this process actually changes research: do authors engage with the feedback and revise their work?

This page tabulates evidence from approximately 57 tracked evaluations based on manual assessment. For each paper where sufficient time has passed, Unjournal staff assessed whether the authors (a) formally or informally responded to the evaluation, and (b) produced an updated version of the paper that reflects the feedback.

For a subset of papers, automated PDF change detection (line-level diffing of before/after versions) supplements the manual coding. The broader background and framing is discussed in The Unjournal’s knowledge base.

LLM Change Attribution Analysis

For papers where a newer version is publicly available (via NBER or arxiv), we compare the pre-evaluation version (the PDF sent to evaluators) against the current version, then use GPT-5 Pro to assess whether the changes plausibly reflect the evaluators’ suggestions.

Pipeline (scripts in scripts/, run from project root): 1. fetch_latest_papers.py — downloads latest PDFs from NBER/arxiv for all papers with qualifying DOIs 2. run_paper_change_llm.py — extracts text, computes diffs, runs a 3-step LLM analysis per paper: (a) identify major changes, (b) extract evaluator suggestions from the evaluation markdown, (c) assess whether each change aligns with a suggestion

NoteMethodology and caveats
  • Before version: the PDF evaluated by Unjournal evaluators (stored in papers/)
  • After version: latest version fetched from NBER or arxiv in April 2026
  • Attribution conservatism: GPT-5 Pro is instructed to mark changes as “direct” or “indirect” only when there is clear conceptual alignment with a specific evaluator suggestion; coincidental improvements are labelled “possible” or “unrelated”
  • Temporal caveat: a newer PDF does not guarantee the change happened in response to the evaluation; some papers were already in revision. The deposit date > UJ pub date flag in the manual coding helps but is not definitive
  • Coverage: 30 papers had fetchable DOIs (NBER or arxiv); of these, 11 showed meaningful text changes (≥15 line edits or ≥0.5% size change); 3 papers with no matching pre-evaluation PDF were excluded
  • LLM limitations: the model sees truncated text (60,000 chars per version) and may miss changes in heavily mathematical or figure-dense sections
Load LLM attribution results 
nn <- function(x, default = NA) if (!is.null(x)) x else default

llm_results_path <- "data/paper_change_llm_results.json"

if (file.exists(llm_results_path)) {
  llm_raw <- fromJSON(llm_results_path, simplifyVector = FALSE)

  llm_df <- lapply(llm_raw, function(r) {
    oa <- r$overall_assessment
    data.frame(
      paper_title      = nn(r$paper_title, ""),
      adj_status       = nn(r$adj_status, ""),
      deposit_after_uj = isTRUE(r$deposit_after_uj),
      text_chg_pct     = nn(r$text_length_change_pct, NA_real_),
      additions        = nn(r$additions_count, NA_integer_),
      deletions        = nn(r$deletions_count, NA_integer_),
      n_major_changes  = length(nn(r$major_changes, list())),
      n_suggestions    = length(nn(r$evaluator_suggestions, list())),
      pct_influenced   = if (!is.null(oa)) nn(oa$pct_likely_influenced, NA_real_) else NA_real_,
      attr_confidence  = if (!is.null(oa)) nn(oa$confidence, NA_real_) else NA_real_,
      narrative        = if (!is.null(oa)) nn(oa$narrative, "") else "",
      eval_found       = !is.null(r$eval_file) && nchar(nn(r$eval_file, "")) > 0,
      skipped          = !is.null(r$skipped_reason),
      stringsAsFactors = FALSE
    )
  }) |> bind_rows()

  llm_analyzed    <- llm_df |> filter(!skipped & eval_found & n_major_changes > 0)
  n_analyzed      <- nrow(llm_analyzed)
  n_total_fetched <- nrow(llm_df)
  med_pct         <- median(llm_analyzed$pct_influenced, na.rm = TRUE)
  n_high          <- sum(!is.na(llm_analyzed$pct_influenced) &
                           llm_analyzed$pct_influenced >= 30, na.rm = TRUE)
} else {
  message("LLM results not found — run scripts/run_paper_change_llm.py first")
  llm_df <- llm_analyzed <- data.frame()
  n_analyzed <- n_total_fetched <- n_high <- 0
  med_pct <- NA_real_
}

## LLM Change Attribution Analysis

For papers where a newer version is publicly available (via NBER or arxiv), we compare the pre-evaluation version (the PDF sent to evaluators) against the current version, then use GPT-5 Pro to assess whether the changes plausibly reflect the evaluators' suggestions.

**Pipeline** (scripts in `scripts/`, run from project root):
1. `fetch_latest_papers.py` — downloads latest PDFs from NBER/arxiv for all papers with qualifying DOIs
2. `run_paper_change_llm.py` — extracts text, computes diffs, runs a 3-step LLM analysis per paper: (a) identify major changes, (b) extract evaluator suggestions from the evaluation markdown, (c) assess whether each change aligns with a suggestion

::: {.callout-note collapse="true"}
## Methodology and caveats

- **Before version**: the PDF evaluated by Unjournal evaluators (stored in `papers/`)
- **After version**: latest version fetched from NBER or arxiv in April 2026
- **Attribution conservatism**: GPT-5 Pro is instructed to mark changes as "direct" or "indirect" only when there is clear conceptual alignment with a specific evaluator suggestion; coincidental improvements are labelled "possible" or "unrelated"
- **Temporal caveat**: a newer PDF does not guarantee the change happened *in response* to the evaluation; some papers were already in revision. The `deposit date > UJ pub date` flag in the manual coding helps but is not definitive
- **Coverage**: 30 papers had fetchable DOIs (NBER or arxiv); of these, 11 showed meaningful text changes (≥15 line edits or ≥0.5% size change); 3 papers with no matching pre-evaluation PDF were excluded
- **LLM limitations**: the model sees truncated text (60,000 chars per version) and may miss changes in heavily mathematical or figure-dense sections
:::

```{r}
#| label: llm-attribution-load
#| code-summary: "Load LLM attribution results"

nn <- function(x, default = NA) if (!is.null(x)) x else default

llm_results_path <- "data/paper_change_llm_results.json"

if (file.exists(llm_results_path)) {
  llm_raw <- fromJSON(llm_results_path, simplifyVector = FALSE)

  llm_df <- lapply(llm_raw, function(r) {
    oa <- r$overall_assessment
    data.frame(
      paper_title      = nn(r$paper_title, ""),
      adj_status       = nn(r$adj_status, ""),
      deposit_after_uj = isTRUE(r$deposit_after_uj),
      text_chg_pct     = nn(r$text_length_change_pct, NA_real_),
      additions        = nn(r$additions_count, NA_integer_),
      deletions        = nn(r$deletions_count, NA_integer_),
      n_major_changes  = length(nn(r$major_changes, list())),
      n_suggestions    = length(nn(r$evaluator_suggestions, list())),
      pct_influenced   = if (!is.null(oa)) nn(oa$pct_likely_influenced, NA_real_) else NA_real_,
      attr_confidence  = if (!is.null(oa)) nn(oa$confidence, NA_real_) else NA_real_,
      narrative        = if (!is.null(oa)) nn(oa$narrative, "") else "",
      eval_found       = !is.null(r$eval_file) && nchar(nn(r$eval_file, "")) > 0,
      skipped          = !is.null(r$skipped_reason),
      stringsAsFactors = FALSE
    )
  }) |> bind_rows()

  llm_analyzed    <- llm_df |> filter(!skipped & eval_found & n_major_changes > 0)
  n_analyzed      <- nrow(llm_analyzed)
  n_total_fetched <- nrow(llm_df)
  med_pct         <- median(llm_analyzed$pct_influenced, na.rm = TRUE)
  n_high          <- sum(!is.na(llm_analyzed$pct_influenced) &
                           llm_analyzed$pct_influenced >= 30, na.rm = TRUE)
} else {
  message("LLM results not found — run scripts/run_paper_change_llm.py first")
  llm_df <- llm_analyzed <- data.frame()
  n_analyzed <- n_total_fetched <- n_high <- 0
  med_pct <- NA_real_
}
```
