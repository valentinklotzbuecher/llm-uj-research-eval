Overview

The Unjournal commissions open, structured evaluations of working papers in economics and social science. A natural question is whether this process actually changes research: do authors engage with the feedback and revise their work?

This page tabulates evidence from approximately 57 tracked evaluations based on manual assessment. For each paper where sufficient time has passed, Unjournal staff assessed whether the authors (a) formally or informally responded to the evaluation, and (b) produced an updated version of the paper that reflects the feedback.

For a subset of papers, automated PDF change detection (line-level diffing of before/after versions) supplements the manual coding. The broader background and framing is discussed in The Unjournal’s knowledge base.

Combined Evidence of Paper Updating

Two evidence streams are combined below:

  • Manual classification (all 57 papers): Unjournal staff assessed whether authors engaged with feedback and revised their work.
  • LLM change-attribution (8 papers): For papers with fetchable NBER/arxiv DOIs and meaningful text changes, Claude Opus 4.6 compared pre-evaluation PDFs against current versions in a 3-step pipeline — (a) identify major changes, (b) extract evaluator suggestions, (c) assess whether changes plausibly reflect suggestions.
NotePipeline and caveats

Scripts (run from project root): scripts/fetch_latest_papers.py → scripts/run_paper_change_llm.py

  • Before version: PDF evaluated by Unjournal evaluators (papers/); After version: latest from NBER/arxiv, fetched April 2026
  • Model: Claude Opus 4.6, temperature 0.2; instructed to be conservative — only “direct” or “indirect” attribution when there is clear conceptual alignment with a specific suggestion
  • Coverage: 30 papers had fetchable DOIs; 8 showed meaningful text changes (≥15 line edits or ≥0.5% size change) and matched evaluation files; 3 papers lacked pre-evaluation PDFs; the 3 manually-confirmed updates were also LLM-analyzed using --paper to override the skip filter
  • Temporal caveat: newer version ≠ evaluation-driven change; some papers were already in revision. The deposit date > UJ pub date flag helps but is not definitive
  • LLM limitations: text truncated at 60,000 chars per version; may miss changes in mathematical/figure-dense sections
Load and merge LLM + manual data 
nn <- function(x, default = NA) if (!is.null(x)) x else default

llm_results_path <- "data/paper_change_llm_results.json"

if (file.exists(llm_results_path)) {
  llm_raw <- fromJSON(llm_results_path, simplifyVector = FALSE)

  llm_df <- lapply(llm_raw, function(r) {
    oa <- r$overall_assessment
    data.frame(
      paper_title      = nn(r$paper_title, ""),
      adj_status_csv   = nn(r$adj_status, ""),
      deposit_after_uj = isTRUE(r$deposit_after_uj),
      text_chg_pct     = nn(r$text_length_change_pct, NA_real_),
      additions        = nn(r$additions_count, NA_integer_),
      deletions        = nn(r$deletions_count, NA_integer_),
      n_major_changes  = length(nn(r$major_changes, list())),
      n_suggestions    = length(nn(r$evaluator_suggestions, list())),
      pct_influenced   = if (!is.null(oa)) nn(oa$pct_likely_influenced, NA_real_) else NA_real_,
      attr_confidence  = if (!is.null(oa)) nn(oa$confidence, NA_real_) else NA_real_,
      narrative        = if (!is.null(oa)) nn(oa$narrative, "") else "",
      eval_found       = !is.null(r$eval_file) && nchar(nn(r$eval_file, "")) > 0,
      skipped          = !is.null(r$skipped_reason),
      stringsAsFactors = FALSE
    )
  }) |> bind_rows()

  llm_analyzed <- llm_df |>
    filter(!skipped & eval_found & n_major_changes > 0 & !is.na(pct_influenced))

  # Enrich with area and PubPub links from main df
  llm_enriched <- llm_analyzed |>
    left_join(
      df |> select(paper_title, research_area, pubpub_link),
      by = "paper_title"
    ) |>
    mutate(
      manual_tier = case_when(
        adj_status_csv == "evidence of updating"          ~ "Confirmed update",
        adj_status_csv == "Stated intention to update"    ~ "Stated intention",
        adj_status_csv == "mixed evidence/minor updating" ~ "Mixed / minor",
        adj_status_csv == "Unlikely to update"            ~ "Unlikely",
        TRUE                                              ~ "Unclassified"
      ),
      combined_tier = case_when(
        manual_tier == "Confirmed update" & pct_influenced >= 40 ~ "Confirmed + strong LLM",
        manual_tier == "Confirmed update"                        ~ "Confirmed + weaker LLM",
        pct_influenced >= 30                                     ~ "LLM: likely influenced",
        pct_influenced >= 10                                     ~ "LLM: possibly influenced",
        TRUE                                                     ~ "LLM: largely independent"
      ),
      combined_tier = factor(combined_tier, levels = c(
        "Confirmed + strong LLM", "Confirmed + weaker LLM",
        "LLM: likely influenced", "LLM: possibly influenced",
        "LLM: largely independent"
      ))
    )

  n_analyzed      <- nrow(llm_enriched)
  n_total_fetched <- nrow(llm_df)
  med_pct         <- median(llm_enriched$pct_influenced, na.rm = TRUE)
  n_high          <- sum(llm_enriched$pct_influenced >= 30, na.rm = TRUE)
} else {
  message("LLM results not found — run scripts/run_paper_change_llm.py first")
  llm_df <- llm_analyzed <- llm_enriched <- data.frame()
  n_analyzed <- n_total_fetched <- n_high <- 0
  med_pct <- NA_real_
}

## Combined Evidence of Paper Updating {#combined-evidence}

Two evidence streams are combined below:

- **Manual classification** (all 57 papers): Unjournal staff assessed whether authors engaged with feedback and revised their work.
- **LLM change-attribution** (8 papers): For papers with fetchable NBER/arxiv DOIs and meaningful text changes, Claude Opus 4.6 compared pre-evaluation PDFs against current versions in a 3-step pipeline — (a) identify major changes, (b) extract evaluator suggestions, (c) assess whether changes plausibly reflect suggestions.

::: {.callout-note collapse="true"}
## Pipeline and caveats

**Scripts** (run from project root): `scripts/fetch_latest_papers.py` → `scripts/run_paper_change_llm.py`

- **Before version**: PDF evaluated by Unjournal evaluators (`papers/`); **After version**: latest from NBER/arxiv, fetched April 2026
- **Model**: Claude Opus 4.6, temperature 0.2; instructed to be conservative — only "direct" or "indirect" attribution when there is clear conceptual alignment with a specific suggestion
- **Coverage**: 30 papers had fetchable DOIs; 8 showed meaningful text changes (≥15 line edits or ≥0.5% size change) and matched evaluation files; 3 papers lacked pre-evaluation PDFs; the 3 manually-confirmed updates were also LLM-analyzed using `--paper` to override the skip filter
- **Temporal caveat**: newer version ≠ evaluation-driven change; some papers were already in revision. The `deposit date > UJ pub date` flag helps but is not definitive
- **LLM limitations**: text truncated at 60,000 chars per version; may miss changes in mathematical/figure-dense sections
:::

```{r}
#| label: llm-attribution-load
#| code-summary: "Load and merge LLM + manual data"

nn <- function(x, default = NA) if (!is.null(x)) x else default

llm_results_path <- "data/paper_change_llm_results.json"

if (file.exists(llm_results_path)) {
  llm_raw <- fromJSON(llm_results_path, simplifyVector = FALSE)

  llm_df <- lapply(llm_raw, function(r) {
    oa <- r$overall_assessment
    data.frame(
      paper_title      = nn(r$paper_title, ""),
      adj_status_csv   = nn(r$adj_status, ""),
      deposit_after_uj = isTRUE(r$deposit_after_uj),
      text_chg_pct     = nn(r$text_length_change_pct, NA_real_),
      additions        = nn(r$additions_count, NA_integer_),
      deletions        = nn(r$deletions_count, NA_integer_),
      n_major_changes  = length(nn(r$major_changes, list())),
      n_suggestions    = length(nn(r$evaluator_suggestions, list())),
      pct_influenced   = if (!is.null(oa)) nn(oa$pct_likely_influenced, NA_real_) else NA_real_,
      attr_confidence  = if (!is.null(oa)) nn(oa$confidence, NA_real_) else NA_real_,
      narrative        = if (!is.null(oa)) nn(oa$narrative, "") else "",
      eval_found       = !is.null(r$eval_file) && nchar(nn(r$eval_file, "")) > 0,
      skipped          = !is.null(r$skipped_reason),
      stringsAsFactors = FALSE
    )
  }) |> bind_rows()

  llm_analyzed <- llm_df |>
    filter(!skipped & eval_found & n_major_changes > 0 & !is.na(pct_influenced))

  # Enrich with area and PubPub links from main df
  llm_enriched <- llm_analyzed |>
    left_join(
      df |> select(paper_title, research_area, pubpub_link),
      by = "paper_title"
    ) |>
    mutate(
      manual_tier = case_when(
        adj_status_csv == "evidence of updating"          ~ "Confirmed update",
        adj_status_csv == "Stated intention to update"    ~ "Stated intention",
        adj_status_csv == "mixed evidence/minor updating" ~ "Mixed / minor",
        adj_status_csv == "Unlikely to update"            ~ "Unlikely",
        TRUE                                              ~ "Unclassified"
      ),
      combined_tier = case_when(
        manual_tier == "Confirmed update" & pct_influenced >= 40 ~ "Confirmed + strong LLM",
        manual_tier == "Confirmed update"                        ~ "Confirmed + weaker LLM",
        pct_influenced >= 30                                     ~ "LLM: likely influenced",
        pct_influenced >= 10                                     ~ "LLM: possibly influenced",
        TRUE                                                     ~ "LLM: largely independent"
      ),
      combined_tier = factor(combined_tier, levels = c(
        "Confirmed + strong LLM", "Confirmed + weaker LLM",
        "LLM: likely influenced", "LLM: possibly influenced",
        "LLM: largely independent"
      ))
    )

  n_analyzed      <- nrow(llm_enriched)
  n_total_fetched <- nrow(llm_df)
  med_pct         <- median(llm_enriched$pct_influenced, na.rm = TRUE)
  n_high          <- sum(llm_enriched$pct_influenced >= 30, na.rm = TRUE)
} else {
  message("LLM results not found — run scripts/run_paper_change_llm.py first")
  llm_df <- llm_analyzed <- llm_enriched <- data.frame()
  n_analyzed <- n_total_fetched <- n_high <- 0
  med_pct <- NA_real_
}
```
